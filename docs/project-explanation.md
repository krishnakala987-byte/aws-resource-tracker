# AWS Resource Tracker — Project Explanation

## Introduction

AWS Resource Tracker is a DevOps automation project built using Bash scripting and AWS CLI.

The purpose of this project is to automate AWS resource visibility and help cloud engineers quickly monitor infrastructure resources directly from the terminal.

---

# Problem Statement

Managing cloud infrastructure manually becomes difficult as AWS resources increase.

DevOps engineers often need a quick way to:

- Monitor infrastructure
- Track running resources
- Verify AWS configurations
- Improve operational visibility
- Support cloud cost optimization

This project solves that problem through automation.

---

# Solution

This Bash script automates AWS resource tracking by:

1. Validating user input
2. Verifying AWS CLI installation
3. Checking AWS authentication
4. Fetching AWS resources
5. Displaying formatted outputs
